# SmartBus

SmartBus is a microservices-based bus booking platform inspired by RedBus. The platform aggregates multiple travel operators and allows users to search, compare, book, and manage bus tickets.

## Features

- User Authentication & Authorization
- Bus Search & Filtering
- Seat Selection & Booking
- Payment Processing
- Travel Operator Management
- Ticket Cancellation & Refunds
- Notifications (Email/SMS)
- Reviews & Ratings
- Live Bus Tracking
- Analytics Dashboard

## Architecture

- API Gateway
- Auth Service
- User Service
- Operator Service
- Search Service
- Inventory Service
- Booking Service
- Payment Service
- Notification Service
- Review Service
- Tracking Service
- Analytics Service
